CONFIGURATION                                             *arf-configuration*

Set only the options you want to change, using opts in your lazy.nvim spec.
Previous flat settings, signs.range.hl, and the Lua summary() shorthand are
not supported. Use inspect("base::summary"); :ArfSummary remains available.
Nested options merge individually. Unknown settings are rejected. Repeated
calls to setup() merge the
supplied options into the current configuration.

>lua
    require("arf").setup({
      executable = "arf",
      pid = nil,                  -- nil: start a session; number: use an existing session
      startup_timeout = 10000,    -- milliseconds
      eval_timeout = 300000,      -- milliseconds per evaluation

      output = {
        max_bytes = 1048576,      -- retained text per evaluation, including errors
        tibble = {
          max_rows = false,      -- false preserves R's settings
          width = "auto",        -- false, "auto", positive integer, or "all"
        },
      },

      inline = {
        max_lines = 20,          -- body lines, excluding notices and images
      },

      float_window = {           -- shared by saved output and object inspections
        width = "60%",           -- "auto", positive integer, or "1%" to "100%"
        max_height = 30,
      },

      image = {
        render = {              -- PNG generated by R
          width_px = 1200,
          height_px = 800,
          dpi = 180,
        },
        display = {             -- display limits in terminal cells
          max_width = 100,      -- columns
          max_height = 30,      -- rows
        },
      },

      theme = "default",         -- "default", "auto", or "neon"

      signs = {
        enabled = true,
        priority = 5,
        range = { text = "│" },
        success = { text = "│", hl = "ArfSignSuccess" },
        error = { text = "│", hl = "ArfSignError" },
        interrupted = { text = "│", hl = "ArfSignInterrupted" },
        running = {
          text = "…",             -- static symbol when animation is disabled
          hl = "ArfSignRunning",
          frames = { "⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏" },
          interval = 80,          -- milliseconds
        },
      },
    })
<

SESSION                                                         *arf-session*

- executable: command name or executable path. To change the executable for a
  running session, use ArfStop and evaluate again.
- pid: omitted by default for automatic startup. To use an existing session,
  obtain its PID with arf ipc list and supply it as a number. Manage its
  lifecycle and working directory separately. ArfStop does not stop an
  external session or clear its results.
- startup_timeout: startup wait time. Failed or timed-out startup is retried
  on the next evaluation.
- eval_timeout: IPC response wait time for each evaluation, not for the entire
  ArfRunAll sequence. A timeout alone does not stop R computation; use ArfStop
  to terminate the owned session. Stop evaluations in an external session
  separately.

PLOTS                                                             *arf-plots*

Plots are stacked in generation order. image.display.max_width /
image.display.max_height cap
each image's display size in cells; image.render.width_px /
image.render.height_px / image.render.dpi
set PNG dimensions in pixels and resolution in dpi. The window also constrains
display size.

PNG settings take effect on re-evaluation. Increasing pixels and DPI
proportionally may improve sharpness while preserving displayed text and line
sizes.

OUTPUT AND FLOATS                                       *arf-output-settings*

Set R's printed row count and the inline preview length separately in your
lazy.nvim opts:

>lua
    opts = {
      output = {
        tibble = { max_rows = 100, width = "auto" },
      },
      inline = { max_lines = 20 },
    }
<

This prints up to 100 tibble rows and shows the first 20 lines inline. Read
the rest with :ArfOutput.

- inline.max_lines: inline body lines, excluding separators, notices, and
  images.
- output.tibble.max_rows: maximum tibble rows to print. The default false
  preserves
  R's settings. For individual expressions, use print(df, n = 100) or
  print(df, n = 100, width = Inf) to include omitted columns too. An explicit
  n takes precedence.
- output.max_bytes: retained text per evaluation (default 1 MiB), including
  stdout, stderr, and errors but excluding images. If a retention-limit notice
  appears, increase it and rerun. This does not limit R's memory usage.
- output.tibble.width: false preserves R's settings; "auto" uses the source
  window's
  text width at execution start (excluding gutters); a positive integer sets
  the output width in characters; "all" prints all columns. Finite widths show
  one tier, omit columns that do not fit, and also set R's width, affecting
  other printed output. "all" may be stacked in multiple tiers by tibble. An
  explicit print(..., width = ...) takes precedence. Resizing requires re-
  evaluation.
- float_window.width / float_window.max_height: shared float size for saved
  output, summary,
  and other inspections. float_window.width = "auto" uses the editor width
  minus
  borders and margins when opened; a positive integer specifies columns; a
  string such as "90%" specifies a percentage of the editor width (integer
  1–100%). Floats fit the screen and shrink vertically for short output.
  Images appear only inline.

Numeric size, timeout, and PID settings require positive integers.
inline.max_lines applies on the next display refresh; float sizes apply when
reopened. Changes to output.tibble.max_rows, output.tibble.width, and
output.max_bytes
require re-evaluation.

output.tibble.max_rows and output.tibble.width also apply to object
inspections. The R
options they set are restored after each evaluation.

SIGNS                                                             *arf-signs*

- signs.enabled = false: hide all execution signs.
- signs.range.text = "": hide range markers and keep only the final-line
  status.
- Each text: a symbol occupying 1–2 display cells, or an empty string to hide
  it.
- Each hl: a highlight group name; see |arf-highlights|.
- signs.priority: a non-negative integer; higher values take precedence.
  Defaults to 5.
- signs.running.frames: animation frames, each 1–2 display cells wide. Two or
  more frames enable animation; an empty list {} or a single frame uses the
  static running.text instead.
- signs.running.interval: a positive frame interval in milliseconds; defaults
  to 80.

By default, successful, failed, and interrupted ranges use │ on every line,
colored by signs.success.hl, signs.error.hl, or signs.interrupted.hl.
Running ranges use signs.running.hl throughout, with a spinner on the last
line. Nerd Font is not required.
signs.range specifies only text. All lines use the execution status color.

To use distinct symbols on the final line:

>lua
    require("arf").setup({
      signs = {
        range = { text = "│" },
        success = { text = "✓" },
        error = { text = "✗" },
      },
    })
<

The spinner appears on the last line of the running range. Configuration
changes apply to subsequent runs. If signs are hidden, check :set
signcolumn=yes.

API                                                                 *arf-api*

Commands and custom keymaps can use the same Lua API:

>lua
    local arf = require("arf")

    arf.setup(opts)       -- Configure the plugin; see Configuration
    arf.run()             -- Run the top-level expression containing the cursor
    arf.run(3, 5)         -- Run complete lines 3–5 (1-based, inclusive)
    arf.run_all()         -- Run all top-level expressions in the current buffer in order
    arf.clear()           -- Clear current-buffer results, images, and signs; keep R objects
    arf.clear(bufnr)      -- Clear a buffer; 0 means the current buffer
    arf.inspect(fn, opts) -- Call an R function on the object under the cursor; opts.title is optional
    arf.objects()         -- Pick a global R object to inspect
    arf.output()          -- Show saved output at the cursor without evaluating R again
    arf.copy_plot()       -- Copy the most recent plot image to the clipboard
    arf.interrupt()       -- Interrupt evaluation and stop subsequent expressions; keep R objects
    arf.stop()            -- Terminate the owned session and clear results in all buffers
<

R evaluation through run, run_all, inspect, and objects is asynchronous. clear
does not interrupt running R code; use stop to terminate the owned session.

HIGHLIGHTS                                                   *arf-highlights*

Output, floats, and signs use dedicated highlight groups. Select their
defaults with theme:

- "default" (default): a neutral gray palette with restrained status colors.
- "auto": follow the current colorscheme.
- "neon": purple backgrounds with vivid text and status colors.

default and neon follow background for dark and light variants. Only arf
highlights change.

>lua
    require("arf").setup({ theme = "default" })
    -- Use "auto" to follow the colorscheme, or "neon" for neon colors.
<

Repeated setup() calls switch themes immediately. Themes preserve custom Arf*
definitions supplied by the user or colorscheme. The defaults below describe
"auto".

ArfElapsed
    execution time. Auto theme default: DiagnosticInfo.

ArfElapsedStale
    execution time after editing its source. Auto theme default: same as
    ArfOutputStale.

ArfOutput
    normal output. Auto theme default: Normal foreground blended with 15%
    background.

ArfOutputStale
    normal output after editing its source. Auto theme default: Normal
    foreground blended with 50% background; Comment fallback.

ArfSeparator
    full-width rule before inline output. Auto theme default: Normal
    foreground blended with 75% background.

ArfMessage
    message() and package startup messages. Auto theme default:
    DiagnosticInfo.

ArfStderr
    other stderr, including warnings and direct writes. Auto theme default:
    DiagnosticWarn.

ArfFloatNormal
    inspection and output float text and background. Auto theme default:
    NormalFloat.

ArfFloatOutput
    normal output inside floats. Auto theme default: float foreground blended
    with 5% float background.

ArfFloatOutputStale
    normal saved output after editing its source. Auto theme default: float
    foreground blended with 50% float background; Comment fallback.

ArfFloatMessage
    messages inside floats. Auto theme default: ArfMessage.

ArfFloatStderr
    stderr inside floats. Auto theme default: ArfStderr.

ArfFloatError
    errors inside floats. Auto theme default: ArfError.

ArfFloatInterrupted
    interrupted evaluations inside floats. Auto theme default: ArfInterrupted.

ArfFloatWarning
    notices inside floats. Auto theme default: ArfWarning.

ArfFloatEmpty
    empty-output placeholder. Auto theme default: ArfFloatOutput.

ArfFloatBorder
    float borders. Auto theme default: FloatBorder.

ArfFloatTitle
    float titles. Auto theme default: FloatTitle.

ArfSignRunning
    running sign. Auto theme default: DiagnosticInfo.

ArfError
    execution errors. Auto theme default: DiagnosticError.

ArfInterrupted
    interrupted evaluations, without the R error prefix. Auto theme default:
    DiagnosticWarn. Default theme uses muted amber; neon uses vivid yellow,
    matching each theme's warning color for dark and light backgrounds.

ArfWarning
    notices, including image display warnings. Auto theme default:
    DiagnosticWarn.

ArfSignSuccess
    success sign. Auto theme default: DiagnosticOk.

ArfSignError
    error sign. Auto theme default: DiagnosticError.

ArfSignInterrupted
    interrupted evaluation sign. Auto theme default: DiagnosticWarn.

In the "auto" theme, colors come from standard colorscheme groups. When RGB
foreground or background is unavailable, output links to its source group and
the separator links to NonText.

To set your own colors, reapply them on ColorScheme because :colorscheme
clears highlights:

>lua
    local function arf_colors()
      vim.api.nvim_set_hl(0, "ArfOutput", { fg = "#a6adc8" })
      vim.api.nvim_set_hl(0, "ArfSignSuccess", { fg = "#a6e3a1" })
    end
    vim.api.nvim_create_autocmd("ColorScheme", { callback = arf_colors })
    arf_colors()
<

Image placeholder colors are managed by Snacks.

                                                        *:ArfInterrupt*
:ArfInterrupt
    Interrupt the active R evaluation and stop subsequent ArfRunAll
    expressions.
    Keep the session, variables, and saved results, including partial output.
    Also works with an explicit pid. Interruption is cooperative: native code
    may delay it. New runs remain blocked until evaluation completes. A
    rejected or failed
    interrupt may be retried; the remaining expressions stay cancelled.
    Requires arf 0.7.0-beta.2 or later; evaluation outcomes use its status
    field.
